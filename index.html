¿No estás en la misma Wi-Fi?

¡No pasa nada! Gracias al uso de servidores de señalización en la nube y STUN (WebRTC), la aplicación establecerá una conexión directa (P2P) entre tu iPhone y tu PC con Windows cruzando routers de manera inteligente.

Tip: Para velocidades de transferencia extremas o archivos pesados, estar en la misma red Wi-Fi permite velocidades gigabit locales directas.

¡Alojalo tú mismo totalmente gratis!

  1. Crea un repositorio en GitHub con el nombre dropair.
  2. Sube este archivo guardándolo con el nombre exacto de index.html.
  3. Entra en Settings > Pages de tu repositorio, elige la rama main, haz clic en Save y ¡listo!

En unos segundos tu aplicación estará visible públicamente para compartirla con cualquier amigo usando tu propio enlace de GitHub.
